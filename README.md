One sentence, up to 200 characters, on a small moment of wonder in everyday life, judged pairwise by an AI judge that rewards surprise. Free to enter, with a longer window.

The program writes a single sentence to `/output/entry.txt`:

> The escalator handrail outruns my hand by half a step, so for one whole floor I am holding hands with the building itself.

(122 characters, one sentence — inside the 1–200 character gate.)

## Run it

```sh
node main.ts
```
